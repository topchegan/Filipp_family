# Памятка для Claude

## Проект
Платформер «Всем что-то надо от Филиппа». Герой Филипп сбегает из дома от семьи и обязанностей
на дачу к другу Сане. Жена Лера догоняет его по шкале времени.

## Техника
- Чистый HTML + CSS + JavaScript. Без фреймворков, сборщиков и внешних библиотек.
- Canvas 240x136, масштаб в целое число раз, пиксели чёткие.
- Палитра Sweetie 16, использовать ТОЛЬКО эти цвета:
  #1a1c2c #5d275d #b13e53 #ef7d57 #ffcd75 #a7f070 #38b764 #257179
  #29366f #3b5dc9 #41a6f6 #73eff7 #f4f4f4 #94b0c2 #566c86 #333c57
- Игра публикуется через GitHub Pages и тестируется в основном в Safari на iPad,
  поэтому сенсорное управление обязательно.

## Правила общения
- Пользователь — новичок, учится на этом проекте вместе с наставником.
- Писать по-русски, коротко и простыми словами.
- Итоговый ответ после каждой задачи — ОДНИМ блоком кода (в тройных обратных кавычках),
  чтобы его можно было целиком скопировать и переслать наставнику. В ответе: что сделал,
  какие файлы создал или изменил, что проверить, были ли проблемы.
- Делать только то, что просят в задаче, без лишних функций.

## Код
- Комментарии в коде на русском, понятные новичку.

## Файлы
- index.html — страница, холст, экранные кнопки.
- style.css — оформление, масштаб, кнопки.
- game.js — вся логика игры. В начале — CONFIG: все числа баланса (пользователь правит сам).
- sprites.js — спрайты, портреты, иконки (пиксельные карты), мебель, фоны заставок и экранов уровня, функции рисования.
- sprites.html — витрина спрайтов: все анимации крупно.
- docs/characters.md — справочник внешности персонажей. Сверяться с ним при рисовании.
- font.js — пиксельный шрифт 5x7 и функции вывода текста.
- scenes.js — сценарий заставок (его правит пользователь сам). Код туда не класть.
- levels.js — карты уровней: экраны 15x30 символов (правит пользователь сам). Код туда не класть.
- docs/levels.md — инструкция, как менять карту.
