# Как установить игру как приложение

Игра — это PWA (веб-приложение): её можно поставить на экран «Домой» как обычное приложение.
После первого запуска она работает **без интернета**. Адрес игры:
`https://topchegan.github.io/Filipp_family/`

## iPad и iPhone (Safari)

1. Откройте адрес игры **в Safari** (в Chrome на iPad пункта может не быть).
2. Дождитесь, пока игра загрузится (появится заставка).
3. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх, справа в адресной строке).
4. Пролистайте вниз и выберите **«На экран Домой»**.
5. Название можно оставить «Филипп», нажмите **«Добавить»**.
6. На экране «Домой» появится иконка с Филиппом. Игра откроется на весь экран, без адресной строки.

Проверить офлайн-режим: откройте игру с иконки один раз с интернетом, закройте её,
включите «Авиарежим» и снова откройте с иконки — игра должна запуститься.

## Android (Chrome)

1. Откройте адрес игры **в Chrome**.
2. Нажмите меню **⋮** (три точки справа вверху).
3. Выберите **«Установить приложение»** (иногда пункт называется «Добавить на главный экран»).
   Chrome может и сам показать внизу плашку «Установить».
4. Нажмите **«Установить»**. Иконка появится среди приложений.

## Android-приложение (APK) — собирается на GitHub

Игра собрана в настоящее Android-приложение (Capacitor). Все файлы игры лежат внутри,
интернет не нужен. Готовые APK лежат на странице релизов:
**https://github.com/topchegan/Filipp_family/releases**

### Как скачать и установить APK на Android

1. На телефоне откройте страницу релизов (ссылка выше) в **Chrome**.
2. В самом верхнем релизе раскройте **Assets** и нажмите **`Filipp-v0.26.apk`** (номер — последний).
3. Когда файл скачается, нажмите **«Открыть»** (или найдите его в «Загрузках»).
4. Android спросит разрешение на установку из неизвестных источников:
   **«Настройки»** → включить **«Разрешить установку из этого источника»** для Chrome →
   вернуться назад. (Или заранее: Настройки → Приложения → Chrome →
   «Установка неизвестных приложений» → Разрешить.)
5. Нажмите **«Установить»**. Если Google Play Защита скажет «Неизвестное приложение» —
   **«Подробнее»** → **«Всё равно установить»**. Это нормально: приложения нет в Google Play.
6. На экране появится иконка **«Филипп»**. Игра идёт на весь экран, только горизонтально,
   экран не гаснет. Кнопка «Назад» Android: в игре — пауза, в меню — назад, на титуле — выход.

### Как запустить сборку с iPad

1. В Safari откройте **https://github.com/topchegan/Filipp_family** (войдите в GitHub).
2. Вкладка **Actions** (если её не видно — пролистайте строку вкладок вправо).
3. Слева в списке выберите **«Android APK»**.
4. Справа нажмите **«Run workflow»** → ветка **main** → зелёная кнопка **«Run workflow»**.
5. Сборка идёт 5–10 минут. Зелёная галочка — готово: APK появился в **Releases**.
   Красный крестик — нажмите на сборку и посмотрите, на каком шаге ошибка.

Сборка запускается и сама, если в репозиторий отправить тег версии (например `v0.27`).
Номер версии берётся из `version.js`. Если релиз этой версии уже есть, файл в нём заменяется.

### Ключ подписи (один раз)

Каждый APK подписывается **одним и тем же ключом** — только тогда новая версия ставится
поверх старой. Ключ и пароль хранятся в секретах репозитория
(Settings → Secrets and variables → Actions):
- `ANDROID_KEYSTORE_BASE64` — сам ключ (файл keystore, записанный текстом);
- `ANDROID_KEYSTORE_PASSWORD` — пароль от ключа.

**Сохраните ключ и пароль в надёжном месте** (менеджер паролей, заметка с паролем).
GitHub не показывает секреты обратно. Если ключ потеряется, новый APK не встанет поверх
старого: друзьям придётся удалить игру и поставить заново (прогресс пропадёт).
В репозиторий ключ класть нельзя — он публичный.

### Как обновлять

1. Поднять версию в `version.js` (как обычно) и отправить изменения в main.
2. Запустить сборку (Actions → Android APK → Run workflow).
3. Друзья скачивают новый APK из Releases и ставят его **поверх** старого — удалять игру
   не нужно, звёздочка «ИГРА ПРОЙДЕНА» сохранится.

### Для разработчика

- `package.json`, `capacitor.config.json` — настройки Capacitor (имя «Филипп»,
  идентификатор `com.topchegan.filipp`).
- `scripts/build-www.js` — собирает папку `www` из файлов игры (её нет в репозитории).
  Копирует всё из корня, кроме служебного (docs, android, sw.js, витрина…).
- `android/` — проект Android: полный экран, горизонталь, экран не гаснет (MainActivity.java),
  иконки, номер версии из `version.js` (app/build.gradle).
- `.github/workflows/android.yml` — сборка APK и релиз.
- Сайт на GitHub Pages работает как раньше, из корня. В приложении service worker
  не регистрируется — файлы и так внутри.

## Как получить APK для Android через pwabuilder.com

Другой способ — не нужен, если пользуетесь сборкой выше.

APK — это файл установки Android-приложения: его можно отправить другу или выложить в магазин.

1. Откройте **https://www.pwabuilder.com** на компьютере.
2. Вставьте адрес игры `https://topchegan.github.io/Filipp_family/` и нажмите **«Start»**.
3. Сайт проверит игру и покажет оценку манифеста, service worker и безопасности.
   Красных ошибок быть не должно (иконки, манифест и офлайн-режим уже сделаны).
4. Нажмите **«Package For Stores»** (или «Generate Package»).
5. Выберите **Android** → **«Generate Package»**.
6. В настройках можно оставить всё как есть. Важное:
   - **Package ID** — например `io.github.topchegan.filipp` (латиницей, через точки);
   - **App name** — «Всем что-то надо от Филиппа», **Short name** — «Филипп»;
   - **Signing key** — «Create new» (новый ключ).
7. Нажмите **«Download Package»** — скачается zip-архив.
8. Внутри архива:
   - файл **`.apk`** — его можно скопировать на телефон и установить
     (Android попросит разрешить установку из неизвестных источников);
   - файл **`.aab`** — для загрузки в Google Play;
   - файл **`signing.keystore`** и текст с паролями — **сохраните их!** Без них нельзя будет
     выпустить обновление приложения в Google Play.
9. Без адресной строки приложение будет, только если положить файл `assetlinks.json` из архива
   в **корень сайта**: `https://topchegan.github.io/.well-known/assetlinks.json`. Игра лежит
   в папке `/Filipp_family/`, а корень — это отдельный репозиторий `topchegan.github.io`.
   Его нужно создать отдельно (могу помочь). Без этого файла APK тоже работает,
   но сверху может быть видна тонкая полоска с адресом.

## Как обновляется игра

- Каждая новая версия (номер в `version.js`) — новый офлайн-кэш. При следующем запуске
  с интернетом игра сама скачает новую версию и удалит старую.
- Без интернета запускается последняя скачанная версия.
- Номер версии виден в углу экрана.
- Если в игру добавили новый файл (js, css, картинку), его нужно дописать в список `FILES`
  в `sw.js`, иначе без интернета он не загрузится.
