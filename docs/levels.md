# Как менять карту уровня

Карта уровня лежит в файле `levels.js`.

## Как устроен уровень

```
Уровень 1 «Утро. Побег из дома»
├─ ЧАСТЬ 1 «Первый этаж» — 7 экранов → выход N (лестница наверх)
├─ ЧАСТЬ 2 «Второй этаж» — 6 экранов → выход N (окно) + сценка с простынями
├─ ЧАСТЬ 3 «Двор»        — 9 экранов → калитка E («ВЫХОД»)
└─ БОСС «Вася и Настя»   → звонок бабушки → сценка в квартире бабушки → уровень 2

Уровень 2 «День. Двор у мамы и бабушки»
├─ ЧАСТЬ 1 «Подъезд»          — 6 экранов → выход N (дверь подъезда)
├─ ЧАСТЬ 2 «Детская площадка» — 7 экранов → выход N (табличка со стрелкой)
├─ ЧАСТЬ 3 «Парковка и арка»  — 7 экранов → арка E
└─ БОСС «Мама» → плов +3 → звонок начальника → «КОНЕЦ УРОВНЯ 2» → этап «ЗА РУЛЁМ» → офис

Уровень 3 «Вечер. Офис»
├─ ЧАСТЬ 1 «Отдел продаж»                  — 7 экранов → выход N
├─ ЧАСТЬ 2 «Кухня, курилка и бухгалтерия»  — 6 экранов → выход N
├─ ЧАСТЬ 3 «Склад образцов и выход»        — 6 экранов → турникет E
└─ БОСС «Начальник» (годовой отчёт) → звонок Сани → «КОНЕЦ УРОВНЯ 3» → машина дома, дальше пешком

Уровень 4 «Ночь. Пешком к Сане»
├─ ЧАСТЬ 1 «Гаражи»       — 8 экранов → выход N
├─ ЧАСТЬ 2 «Теплотрасса»  — 8 экранов → выход N
├─ ЧАСТЬ 3 «Заправка»     — 8 экранов → знак «ПЕРЕХОД» E
└─ БОСС «Титя» → этап «Переход дороги» → калитка Сани → ФИНАЛ (дача, итоги дня, титры)
```

- Уровень делится на **части** (`parts`). Каждая часть — свой список **экранов** (`screens`),
  они идут друг за другом слева направо.
- В каждой части ровно одна буква `P` — где Филипп появляется.
- В каждой части, кроме последней, ровно один выход `N`. Филипп дошёл до него — короткое
  затемнение, титр «ЧАСТЬ 2. ВТОРОЙ ЭТАЖ», дальше следующая часть.
- У части может быть `exitScene` — сценка из `scenes.js` перед переходом (у второго этажа это
  `sheets`: «ПРОСТЫНИ... КАК В КИНО.» и спуск по простыне).
- В последней части ровно одна калитка `E` — финиш уровня.
- **Шкала HUD, Лера и часы считают весь уровень целиком.** Лера едет по шкале без остановок
  через все части, часы тоже идут. Пока идёт сценка или титр, игра стоит на паузе.

```
    parts: [
      {
        name: 'Первый этаж',
        screens: [
          { bg: 'livingRoom', map: [ ...15 строк... ] },
          ...
        ],
      },
      {
        name: 'Второй этаж',
        exitScene: 'sheets',
        screens: [ ... ],
      },
      ...
    ],
```

Каждый экран — картинка из символов: **ровно 15 строк по 30 символов**. Один символ — одна
плитка 8x8 пикселей.

```
          {
            bg: 'kitchen',
            map: [
              '..............................',
              ...
              '..T......S.........F.....C....',
              '##############################',
            ],
          },
```

- `bg` — фон экрана. Список фонов — в начале `levels.js` (гостиная, кухня, ванная, кладовка,
  спальня, комнаты детей, двор…). От фона зависит, как выглядят пол `#` и полки `-`.
- `map` — сама карта. Какие буквы что значат — смотри «Легенда» ниже.

## Легенда: общие символы и свои у каждого уровня

Букв на всё не хватает, поэтому легенда из двух уровней.

**1. Общие символы — одинаковые во ВСЕХ уровнях.** Эти буквы нельзя занимать в легенде уровня:

| Символ | Что это |
|---|---|
| `.` | пусто |
| `#` | пол или стена |
| `-` | полка: снизу насквозь, сверху стоять (в ванной — верёвка с бельём) |
| `P` | старт части (ровно один в каждой части и на арене) |
| `C` | телефон-звонок |
| `N` | выход в следующую часть |
| `E` | финиш: калитка «ВЫХОД» на арену босса (на уровне 2 — арка, на фоне `archYard`) |
| `b` | пиво |
| `x` | сигареты |
| `u` | кофе |

**2. Свои символы у каждого уровня** — в `levels.js`, в поле `legend` внутри уровня:

```
    legend: {
      D: 'sofa',          // диван 5x2 — на нём можно лечь
      k: 'kirill',        // Кирилл
      l: 'lego',          // лего на полу
      ...
    },
```

Слева буква на карте, справа — что это: имя предмета (`sofa`, `table`, `wardrobe`…) или особая
вещь (`kirill`, `cat`, `vacuum`, `vasya`, `nastya`, `lego`, `rake`, `lera`). Полный список уровня 1
с подписями — прямо в `levels.js`. У уровня 2 своя `legend`: те же буквы могут означать
совсем другое (например, `D` на уровне 2 — диван, а `G` — дерево). Особые вещи уровня 2:
`neighbor`, `dog`, `biker`, `scooter`, `sprinkler`, `gossip2`, `gossip3`, `keybox`.

Коротко про уровень 1:
- `L` — Лера с досками у двери (картинка, не враг);
- мебель и вещи — предметы, все твёрдые: сквозь них не пройти, сверху можно стоять;
- `j` — **батут**: подбрасывает на 8 плиток, им перелетают через высокий забор `z`;
- `I` — **лестница**: 8 ступенек, на каждую запрыгивают как на платформу;
- `K` — корзина 2x2: удобная ступенька перед высоким предметом;
- **враги:** `k` Кирилл, `t` кошка Туся, `w` пылесос (ставятся на плитку над полом или предметом);
- **ловушки:** `l` лего, `i` грабли, `o` горшок с лужей; мангал `f` горячий, сиденье качелей `Q` бьёт.

Коротко про уровень 2:
- **подъезд:** `F` и `H` — лестничные пролёты вниз (ступеньки по полплитки, на них заходишь без
  прыжка). Площадки разной высоты — это плитки `#`. `M` — почтовые ящики на стене (сверху можно
  стоять, под ними пройти), `O` — цветы в горшке, `L` — лифт с табличкой «ЛИФТ НЕ РАБОТАЕТ»
  (картинка, не мешает);
- **площадка:** `S` — горка (лесенка слева, вниз съезжаешь быстро), `K` — карусель (тащит влево),
  `R` — шведская стенка и `J` — турник (перекладины — тонкие платформы), `G` — дерево (ствол
  твёрдый, крона — тонкие платформы), `Z` — песочница, `q` — лужа (скользко);
- **парковка:** машины `A` `B` `X` `Y` (по крышам можно бежать, сигнализация «УИ-УИ-УИ!» — шутка),
  `I` — лавка. Стена с граффити — фон `graffiti`, арка — фон `archYard` с буквой `E`.

## Жизни, враги и ловушки

| Что | Символ | Что делает |
|---|---|---|
| Пиво | `b` | +1 кружка, «бульк». Максимум 5 |
| Кирилл | `k` | Ходит в своей зоне; если Филипп близко на том же полу — бежит «КУПИ ИГРУ!». Касание — минус кружка. Прыжок сверху — «НУ ПА-А-АП!», сидит 3 с |
| Туся | `t` | Гуляет, умывается; рядом — бросается под ноги. Филипп падает на 1,2 с, кружка цела. С крыши спрыгивает |
| Пылесос | `w` | Катается туда-сюда. Сбоку — оглушает на 1 с. Сверху можно ехать |
| Лего | `l` | Наступил — «АЙ!», минус кружка |
| Грабли | `i` | Наступил — «БАМ!», минус кружка, звёздочки |
| Горшок с лужей | `o` | На луже скользко, горшок — препятствие |
| Мангал | `f` | Коснулся — «ГОРЯЧО!», минус кружка |
| Качели | `Q` | Сиденье отбрасывает назад, кружку не отнимает |
| **Уровень 2** | | |
| Сосед с сумками | `s` | Медленно ходит по пролёту. Касание — «ОСТОРОЖНО!», отталкивает, кружка цела |
| Собачка | `d` | Заметила — «ТЯВ!», бежит, вцепляется в шлёпанец: 1,5 с Филипп еле идёт |
| Дорожка великов | `v` | Пока Филипп рядом, раз в 4 с мчится ребёнок на велике. За 1 с — «ДЗЫНЬ-ДЗЫНЬ» и стрелка у края. Удар — минус кружка. Можно перепрыгнуть |
| Самокат | `k` | Катается туда-сюда. Касание отбрасывает, кружка цела |
| Поливалка | `w` | Струя по дуге то влево, то вправо — отталкивает. Пройди, пока она смотрит в другую сторону |
| Лавка с бабушками | `g` (2), `h` (3) | «Зона сплетен» — пунктирный полукруг. Вошёл — застрял, жми «Прыжок» 6 раз («кивни»). Зону можно обойти поверху: по крышам машин и кронам деревьев |
| Ящик с ключами | `y` | +3 гаечных ключа (максимум 9) |

**Оружие (с уровня 2).** У каждого оружия своя кнопка, переключать ничего не нужно:
ключ — клавиша E (запасная — X), на iPad кнопка «Ключ» над «Прыжком»; плов — клавиша F,
на iPad кнопка «Плов» слева от «Прыжка». На кнопках — сколько осталось, кончилось — кнопка тусклая.
Значки «ключ x5» и «плов x1» слева под HUD — просто для информации.
- **Гаечный ключ** (в начале 5, максимум 9): летит по пологой дуге, попал во врага — «БДЗЫНЬ!»,
  враг 2 с сидит со звёздочками. Ребёнка сбивает с велика «ОЙ!». От бабушек отскакивает
  «ХУЛИГАН!» — их зона на 5 с становится больше.
- **Плов** (бабушка даёт 1 контейнер): высыпается на землю полосой в 3 плитки на 8 с.
  Враг наступил — поскользнулся и лежит 2,5 с.
- Между уровнями переносятся кружки (но не меньше 3), ключи и плов.

- После удара Филипп мигает 1,5 секунды и в это время неуязвим.
- Кружки кончились — Лера догоняет (сценка поражения). «ЕЩЁ РАЗ» — с последнего звонка и с 3 кружками.
- Числа (сколько кружек, скорости врагов, сколько лежит после Туси) — в `CONFIG` в начале `game.js`.
- **Не кладите лего и грабли** туда, где нужен разбег перед высоким предметом, и в узкую щель
  между предметами: Филипп будет наступать на них снова и снова. Лучше — открытый пол, где
  ловушку видно заранее.

## Кураж, бустеры и диван

- **Кураж** — шкала в HUD рядом с кружками. Сам убывает от полной до нуля примерно за 2 минуты.
  Выше половины — Филипп в полной силе. Ниже — бег и прыжок плавно слабеют, до 70% на нуле.
  Меньше четверти — шкала мигает, Филипп зевает «ЭХ...». В сценках и звонках кураж не убывает.
- `x` **сигареты** — +40% куража, за Филиппом 2 секунды тянется дымок, надпись «+КУРАЖ».
- `u` **кофе** — 6 секунд быстрее (x1.4) и неуязвим: светится, над головой пар, сквозь врагов
  и ловушки. Потом 2 секунды «отходняк»: медленнее, «ЗЕ-Е-ЕВ...». Кофе ставьте перед трудными местами.
- `b` **пиво** — +1 кружка и «подпитие» на 8 секунд: Филиппа слегка тянет то влево, то вправо,
  тормозит с запозданием, прыжок выше, в бою бросок дальше, иногда «ИК!». Второе пиво подряд — сильнее и дольше.
- **Диван `D` и шезлонг `e`:** постоять на них 1 секунду неподвижно — Филипп ложится («ХР-Р-Р...»)
  и быстро восстанавливает кураж. Любая кнопка — встаёт. Лера в это время идёт!
- `y` — кофемашина (твёрдая, как ступенька). Кофе `u` ставят рядом или на неё.
- Активные эффекты (кофе, «отходняк», подпитие) видны в HUD значком с убывающей полоской.
- Все числа — в `CONFIG` в начале `game.js`.
- **Осторожно:** на нулевом кураже прыжок с разбега — около 3,5 плитки. Если поставить
  высокий предмет (4 плитки) там, где кураж к этому времени обычно кончается, а рядом нет
  сигарет или дивана, Филипп не перепрыгнет его, пока не отдохнёт.

## Арена босса

В конце `levels.js`, после всех частей, есть блок `boss` — арена босса уровня (один экран,
те же 15 строк по 30 символов). Калитка `E` в последней части ведёт сюда.

- `P` — где стоит Филипп, `v` — Вася, `n` — Настя (ровно по одной).
- `a` — низкая скамейка, `Z` — бортик песочницы: куда запрыгнуть и где увернуться.
- Игрушки (мяч, кубик, мишка) падают сами, их на карту ставить не нужно.

Как устроен бой (все числа — в `CONFIG` в `game.js`):
- Девочки по очереди бегут к папе, иногда подпрыгивают. Догнала — «ПАПА, ДЕРЖИСЬ!»:
  Филипп 2 секунды стоит в обнимку, кружку не теряет.
- Сверху падают игрушки. За секунду до падения на земле появляется тень. По голове — минус кружка.
- Упавшую игрушку подбирают касанием (до 3, видно в HUD рядом с кружками).
- «Бросок» (на iPad — кнопка над «Прыжком», на клавиатуре — E или X) — игрушка летит по дуге.
  Попала — «УРА, МЯЧИК!», девочка 2 секунды играет. После 3 попаданий — играет насовсем.
- **Фаза 2:** одна девочка выбыла — вторая бегает быстрее, игрушки падают чаще, иногда по две.
- Лера идёт и во время боя. При входе на арену она отлетает назад (`bossPushBack`).
  Догнала или кончились кружки — поражение, «ЕЩЁ РАЗ» — с начала арены и с 3 кружками.

### Арена уровня 2: мама

Блок `boss` у уровня 2: `P` — Филипп, `m` — мама (ровно одна), `I` — лавка. Фон `momYard`.
Все числа боя — в `CONFIG.level2` в `game.js` (названия начинаются с `mom`).
- Над ареной шкала **«ВНИМАНИЕ»**, в начале пустая. Полная — победа.
- Мама ходит по правой половине и бросает по дуге:
  - **розовые сердечки** с фразами («ТЫ НЕ ЗВОНИШЬ», «КУШАЕШЬ?»…). Поймал — шкала растёт.
    Упало на землю — шкала чуть падает, мама вздыхает «НУ ВОТ...»;
  - **серые просьбы** (кран, унитаз, лампочка, плитка). Коснулся — Филипп 2 секунды стоит
    «ЛАДНО, ПОСМОТРЮ...». Кружки не отнимает, но Лера идёт.
- Ключ в маму — «ТЫ МЕНЯ СОВСЕМ НЕ СЛУШАЕШЬ!», шкала минус 20%. Плов в маму — «ЭТО ЖЕ
  БАБУШКИН ПЛОВ!», плов пропал.
- **Фаза 2** (шкала больше половины, на шкале — белая засечка): мама идёт к Филиппу «ДАЙ ОБНИМУ!».
  Постоял рядом 2 секунды не двигаясь (над Филиппом растёт полоска) — объятие, шкала +20%,
  потом мама отходит на 4 секунды. Просьб больше, иногда летит большое сердце «ФОТО ИЗ ДЕТСТВА» —
  быстрее, но даёт больше.
- Лера отлетает на `bossPushBack` из `CONFIG.level2` — около минуты на бой.
- Победа: мама даёт 3 плова, потом звонок начальника и конец уровня 2.

## Уровень 3 «Вечер. Офис»

Свои символы — в `legend` уровня 3 в `levels.js`. Все числа — в `CONFIG.level3` в `game.js`.
- **Предметы:** `T` стол с компьютером (по столам можно прыгать), `I` перегородка, `K` кулер (рядом
  лужа — скользко), `X` ксерокс (иногда выплёвывает пачку листов — летит по полу и сбивает с ног
  на 1 с), `F` цветок в кадке, `B` доска «ПРОДАЖИ» (картинка), `M` тумба с микроволновкой,
  `R` холодильник, `A` стол, `J` лавка, `W` шкаф с папками (4 плитки — перед ним ступеньки:
  стопки бумаг `s` и `S`), стеллажи `G` `H` `L` (полки — тонкие платформы), `Q` ресепшен.
- **Особые вещи:** `h` офисное кресло — толкнёшь, откатится; встал сверху — катишься вместе с ним.
  `f` погрузчик — ездит туда-сюда, на крыше и на вилах можно прокатиться, сбоку отталкивает.
  `p` — отсюда, пока Филипп рядом, катятся трубы: удар — минус кружка, их можно перепрыгнуть.
- **Коллеги:** `k` курильщик «ПОКУРИМ?» (поймал — 3 с стоите курите, кураж +30%),
  `g` болтушка «ТЫ СЛЫШАЛ, ЧТО...» (держит, пока не нажмёшь «Прыжок» 6 раз), `c` кофеман «КОФЕ?»
  (2 с стоите, потом эффект кофе), `i` стажёр «А КАК?..» (ходит хвостом, пока он рядом — Филипп на
  30% медленнее; отцепить — ключом, он сядет записывать «ВАЖНО!», или запрыгнуть повыше на стол).
  Ключ оглушает коллег на 2 с, на плове они поскальзываются.
- **Звонки клиентов и «СТРЕСС».** Время от времени звонит рабочий телефон — оранжевый значок над
  головой (телефоны-отмазки Лере — как раньше, тёмные). Пока звонит, шкала «СТРЕСС» под HUD растёт.
  Постоял на месте 1,5 с — ответил («ДА, МЕТАЛЛ-ТОРГ... АРМАТУРА ЕСТЬ!»), стресс падает.
  Стресс полный — «А-А-А!», 3 с держится за голову, стресс падает до половины.
  Фразы клиентов — `CLIENT_LINES` в `scenes.js`.
- Часы — с 19:00 до примерно 19:30, закат в окнах темнеет к концу уровня.

### Арена уровня 3: начальник и годовой отчёт

Блок `boss` у уровня 3: `P` — Филипп, `n` — начальник (ровно один), `Z` — принтер, `D` — стол Филиппа
с компьютером (сквозь него проходишь), `V` — стеклянный кабинет начальника, `T` — столы-платформы.
Фон `chiefArena`. Все числа боя — в `CONFIG.level3` (названия начинаются с `chief`, плюс `bossPushBack`).
- Шкала **«ОТЧЁТ»**: растёт, пока Филипп стоит у компьютера и не двигается («ТЫК-ТЫК»). На 100%
  принтер печатает отчёт: добежать до принтера, взять листы и донести в кабинет начальника.
  Пока несёшь — бросать нельзя, всё летит чаще.
- **Волна 1** (до 33%): из кабинета летят бумажные самолётики «СРОЧНО!» — сбивают от стола, кружка цела.
- **Волна 2** (33–66%): ещё красные листы «ПРАВКИ» к компьютеру — долетел, отчёт минус 10%. Перехватить —
  поймать телом или сбить ключом. Приходят курильщик и болтушка.
- **Волна 3** (66% и дальше): начальник выходит из кабинета «А ЕЩЁ СЛАЙДЫ!», ходит по арене и бросает
  степлер и дырокол по дуге — минус кружка.
- Звонки клиентов и «СТРЕСС» работают и в бою. Ключ сбивает самолётики и листы, оглушает коллег;
  ключ в начальника — «Я ВСЁ ЗАПОМНИЛ!», отчёт минус 10%. На плове поскальзываются все.
- Лера идёт и в бою. Догнала или кончились кружки — поражение, «ЕЩЁ РАЗ» — с начала арены.

## Уровень 4 «Ночь. Пешком к Сане»

Филипп отвёз машину домой (Лера думает, что он ещё на работе) и идёт к Сане пешком:
гаражи → теплотрасса → заправка → дорога. Свои символы — в `legend` уровня 4.
Все числа — в `CONFIG.level4` в `game.js`.
- **Ночь:** чем позже на часах (20:30 → 21:00), тем темнее. Фонари `L` дают круги света. Между
  фонарями темно: враги там — чёрные силуэты с горящими глазами. Вдали дымок мангала Сани —
  чем дальше прошёл, тем он ближе и больше.
- **Гаражи и пустырь:** `G` гараж (по крышам можно бежать; вплотную перед ним ступенька `B` —
  стопка плит), `R` «ракушка», `S` плита, `K` бетонный блок, `H` куст, `q` лужа.
- **Теплотрасса:** `T` трубы (верх — тонкая платформа), `s` — отсюда иногда бьёт пар и отталкивает.
- **Заправка:** `V` навес 12x5 (крыша — тонкая платформа, залезть — с колонки), `Z` колонка,
  `U` шины, `D` бочки, `I` лавочка. Фон `azs` — с магазином «24 ЧАСА», `azsYard` — без него.
- **Финиш:** `E` на фоне `roadSide` — знак «ПЕРЕХОД» и «зебра». Дальше — арена Тити (ниже),
  после победы — этап «Переход дороги».
- **Враги (мультяшные):**
  - `j` наркоман — издалека бросает шприцы по дуге (минус кружка, можно перепрыгнуть), вблизи
    «ШНЫРНЁМСЯ?» — поймал, «НЕ-НЕ-НЕ!», жми «Прыжок» 6 раз. Ключ оглушает на 2 с.
  - `d` бродячая собака — лает, вблизи рывок, укус — минус кружка. Ключ — убегает, скуля. Плов —
    ест его 5 с и забывает про Филиппа.
  - `a` алкаш — шатается, заметил — «ТРЕТЬИМ БУДЕШЬ?» и идёт к Филиппу. Догнал — 2 с стоят вместе
    «ЗА ВСТРЕЧУ!», потом Филипп «подшофе», как от пива (тянет в стороны, хуже тормозит, прыгает
    выше). Ключ — отпускает.
  - `t` и `g` девчонки-подростки (рыжая и тёмненькая) — заметили, бегут хвостом:
    «ДЯДЬ, ДАЙ СИГАРЕТКУ!», «ДЯДЬ, ДАЙ ПОЗВОНИТЬ!». Пока рядом — Филипп медленнее на 30%.
    Отстают через 6 с или если запрыгнуть повыше. Ключ — «ФУ, ДУРАК!», обиделись и ушли насовсем.

## Этап «За рулём»

После звонка начальника (конец уровня 2): титр «СУББОТА. 15:30», сценка у минивэна на домкрате,
этап «За рулём», потом заглушка «ДАЛЬШЕ — ОФИС (СКОРО)». Карты в `levels.js` у этапа нет:
дорога собирается сама из чисел `CONFIG.drive` в `game.js` и каждый раз одинаковая.
- Вид сверху: 3 полосы, минивэн внизу, нос вверх. ← → — руль, скорость растёт сама,
  «Прыжок» (Z) — тормоз, «Бросок» (E или X, на iPad — «Гудок») — «БИ-БИП!»: машина впереди
  в той же полосе уходит в соседнюю, если там свободно. Перезарядка 3 секунды («ГУДОК» в HUD тускнеет).
- Попутные машины медленнее: удар «БАЦ!» — занос, скорость почти ноль. Ямы — «БУМ!», скорость
  падает. Лужи — короткий занос. Пробка — ряды медленных машин с узкими просветами.
- Светофор: подъезжаешь — жёлтый, потом красный (3 с). Проехал на красный — через секунду
  инспектор ГИБДД, 4 секунды «ДОКУМЕНТЫ!».
- Кофе — 4 секунды быстрее. Сигареты — +кураж (кураж переносится дальше).
- HUD: шкала пути до офиса, по ней едет минивэн, а за ним — иконка начальника (время).
  Часы с 15:30. Долго едешь — звонок начальника «ТЫ ГДЕ? КЛИЕНТ УХОДИТ!». Начальник дошёл
  до конца шкалы — поражение «КЛИЕНТ УШЁЛ...», «ЕЩЁ РАЗ» — с начала этапа.
- Что можно менять в `CONFIG.drive`: длину этапа, скорости, частоту машин, где светофоры,
  пробка, кофе и сигареты, тексты рекламных щитов, штраф ГИБДД, предел времени.

### Арена уровня 4: Титя

Один экран: ночь у дороги. Символы арены — в `legend` уровня 4: `P` — Филипп, `Q` — Титя
(ровно один), `J` — фонарный столб (твёрдый, круг света), `O` — автобусная остановка (крыша —
платформа, под ней лампа), `I` — лавка, `W` — колонка. Все числа боя — в `CONFIG.level4`.
- Перед боем: затемнение, титр «БОСС: ТИТЯ», разговор (окно диалога вверху, тексты — `tityaIntro`).
- **Шкала «ЯСНОСТЬ»** (под HUD; кураж на время боя замирает). Кончилась — поражение: «Ти-и-тя...
  а может, правда... разок...», темнота, фары минивэна, «ВОТ ТЫ ГДЕ. САДИСЬ. ДОМОЙ.», потом
  обычная «пристройка» и «ЕЩЁ РАЗ» (с начала арены).
  - Облако дыма («ПФФ»): плывёт и тает за 6 с. Внутри ясность быстро падает, экран лиловеет.
    После облака ещё 3 с «ГЛЮКИ»: ← и → поменяны (над головой значок).
  - Шприц по дуге: минус 20% ясности и отталкивает.
  - Колонка `W`: постоять рядом 1 с — «УМЫЛСЯ!», ясность +40%, перезарядка 8 с («КАП»).
  - Кофе — раз в фазу (на крыше остановки или у колонки): +30% ясности и обычный эффект кофе.
- **Как победить: 3 нокдауна, потом нокаут.** Шкала «ТИТЯ» из 3 делений.
  - Рывок: присед 0,7 с «ПОГНАЛИ!», потом бежит по прямой (наклонился — можно перепрыгнуть).
    Не увернулся — минус кружка. Плов на пути — «ШМЯК!», падает.
  - Столб: перепрыгнутый Титя пробегает дальше немного (48 / 36 / 28 пикселей по фазам)
    и тормозит. Врезается «БОМ!», только если Филипп стоял у самого столба — надо рискнуть.
  - Фазы 2–3: прыгнул над рывком слишком рано — Титя подпрыгивает следом «ОП!» и сбивает.
    Прыгать надо в последний момент.
  - Фазы 2–3: прыжок-атака «ОП-ПА!» — присед 0,9 с, потом прыжок по дуге туда, где Филипп.
    Убегай! Приземлился — полсекунды стоит (ключ попадает). Приземлился на плов — падает.
  - Остановка и лавка — не убежище: Титя запрыгивает следом «ОП!», наверху толкает «НА!»
    (минус кружка). Дым тоже тянется вверх, к Филиппу.
  - Лежит со звёздочками (3 / 2,5 / 2 с по фазам): запрыгни сверху — нокдаун «БАЦ!».
    Не успел — встаёт.
  - Ключ: бодрый Титя ловит «ЛОВИ!» и бросает обратно (отталкивает). Пока выдыхает дым,
    встаёт после падения или стоит после «ОП-ПА!» — ключ попадает, падает на 2 с.
    После нокдауна встаёт злой — тогда ключ не берёт.
  - Без плова бой проходим: столбы и ключи.
- **Фазы** (после каждого нокдауна): 1 — рывки, одиночные шприцы, одно облако;
  2 — шприцы веером по 3, два облака, «ОП-ПА!», подскок над рывком, «ТИТЯ ЗЛИТСЯ!»;
  3 — двойной рывок (развернулся и снова), облака больше, Титя быстрее, чаще «ОП-ПА!»
  и подскоки, лежит меньше («ТИТЯ В ЯРОСТИ!»).
- Нокаут: стоп-кадр «НОКАУТ!» со звёздами, сценка `level4Win`, дальше — «Переход дороги».
- Лера идёт и в бою (`bossPushBack` — около 80–90 с). Догнала или кончились кружки — поражение,
  «ЕЩЁ РАЗ» — с начала арены.

## Этап «Переход дороги»

Конец уровня 4 (после победы над Титей): Филипп у дороги, на той стороне — калитка Сани. Карты в `levels.js` у этапа нет:
дорога собирается сама из чисел `CONFIG.cross` в `game.js` и каждый раз одинаковая.
- Вид сверху, Филипп идёт снизу вверх. Экран сам едет за ним. Снизу вверх: наш тротуар,
  4 полосы вправо, разделительная полоса с травой, 4 полосы влево, тротуар у дачи Сани.
  Посередине стёртая «зебра» — машины её не замечают.
- Управление: «Прыжок» (Z, пробел, ↑, на iPad — «Вперёд») — шаг вперёд через полосу,
  держишь — шагает дальше сам. ↓, E или X (на iPad — «Назад») — шаг назад. ← → — вбок.
- Машины едут быстро, в каждой полосе — своя скорость и свой просвет между машинами
  (`CONFIG.cross.lanes`, можно менять). Ночью у машин горят фары. Машина вот-вот наедет —
  сигналит «БИ-И-П!».
- Сбила машина — «БАЦ!», минус кружка, полсекунды лежит со звёздочками, потом встаёт на
  последнем безопасном месте (тротуар или разделительная полоса) и секунду мигает — не задевают.
- Раз в 11 секунд медленно проезжает Лера на минивэне (надпись «ЛЕРА»). Филипп на дороге
  рядом с ней — «ФИЛИПП?!», её время на 6 секунд ближе. На тротуаре и разделительной не замечает.
- HUD: кружки, часы с 21:00, шкала: иконка Филиппа — сколько перешёл, иконка Леры — время.
  Время вышло или кончились кружки — «Вот ты где. Садись. Домой.», «ЕЩЁ РАЗ» — с начала
  этапа (кружки — как в начале этапа, не меньше 3).
- Перешёл — Филипп заходит в калитку Сани, сценка, дальше — финал.
- Что можно менять в `CONFIG.cross`: время Леры, скорость шага и ходьбы вбок, полосы
  (скорость, просветы, какие машины), когда сигналят, как часто и как медленно едет Лера,
  на сколько она ближе, если заметила.

## Как поменять карту на GitHub с iPad

1. Откройте в Safari `github.com/topchegan/Filipp_family` и войдите в аккаунт.
2. Нажмите на файл `levels.js`.
3. Нажмите значок карандаша (Edit) справа над текстом файла.
4. Найдите нужную часть (`// ===== ЧАСТЬ 2: ВТОРОЙ ЭТАЖ =====`) и экран в ней:
   над каждым экраном есть комментарий, например `// Экран 2. Кухня`.
5. Меняйте символы **внутри кавычек**. Лучше заменять символ на символ (например точку на `#`),
   а не вставлять и удалять — тогда длина строки не изменится.
6. Нажмите зелёную кнопку «Commit changes...», напишите, что поменяли, и ещё раз «Commit changes».
7. Через 1–2 минуты откройте игру и обновите страницу.

## Правила

- В каждой строке **ровно 30 символов**, в каждом экране **ровно 15 строк**.
- Каждая строка в одинарных кавычках `'...'`, в конце строки — запятая.
- Нижняя строка обычно — пол `##############################`.
- В каждой части — **ровно одна** буква `P`. В каждой части, кроме последней, — **ровно один** `N`.
  В последней части — **ровно одна** `E` (финиш), а `N` там не нужен.
- Предметы и `E` ставятся одной буквой в **левый нижний угол** предмета.
  Клетки над ним и справа оставьте точками.
- Высота прыжка зависит от разбега и куража:
  - **с места** — около 2 плиток (даже на нулевом кураже);
  - **с разбега** — до 4,5 плиток при полном кураже, но только около 3 плиток на нулевом.
- **Уровень должен быть проходим при ЛЮБОМ кураже.** На обязательном пути — препятствия
  не выше 3 плиток. Перед предметом в 4 плитки (шкаф, холодильник, кровать, вешалка) ставьте
  вплотную ступеньку в 2 плитки: корзину `K`, ящик `X`, кофемашину `y`, доски `q`.
  Высокие предметы без ступенек — только «короткий путь» или место для наград.
- **Перед высоким предметом оставляйте хотя бы 3–4 плитки пустого пола**, чтобы было где
  разбежаться. Если зажать высокий предмет между другими почти вплотную, Филипп застрянет
  в щели: разбежаться негде.
- `C` — телефон. Филипп касается его — звонок-отмазка Лере, Лера отлетает назад. После звонка
  телефон исчезает, а «ЕЩЁ РАЗ» после поражения начинается с этого места. Ставьте телефон на
  плитку прямо над полом или над предметом, куда можно встать.
- Полку или платформу над полом ставьте не ниже 5-й строки снизу. Ниже Филипп не пройдёт
  под ней в полный рост — она станет препятствием.
- На фоне нарисованы только стены, окна и картины. Всё, обо что можно споткнуться, — предметы карты.
- Новый экран: скопируйте целиком любой экран от `{` до `},` и вставьте после другого.
- Уровень 2: высокий пол площадки в подъезде — плитки `#` до самого низа экрана. Пролёт `F`
  (3 плитки высотой) ставьте так, чтобы его верх был вровень с верхней площадкой, а низ стоял на
  нижней. Поливалку и лавку с бабушками не ставьте вплотную к высокому предмету: после толчка
  или «кивков» нужно место для разбега.

## Что будет при ошибке

Игра проверяет карту при загрузке. Если что-то не так, вместо игры появится тёмный экран
с надписью, где ошибка. Например:

- `ЧАСТЬ 1, ЭКРАН 1, СТРОКА 14: СИМВОЛОВ 29, А НУЖНО 30.` — в строке не хватает символа.
- `ЧАСТЬ 2, ЭКРАН 3, СТРОКА 5, СИМВОЛ 12: НЕИЗВЕСТНЫЙ ЗНАК «Ж».` — такого символа нет в легенде.
- `ЧАСТЬ 3, ЭКРАН 2: СТРОК 14, А НУЖНО 15.` — потерялась строка.
- `ЧАСТЬ 2: НЕТ СТАРТА P.` / `ЧАСТЬ 1: НЕТ ВЫХОДА N В СЛЕДУЮЩУЮ ЧАСТЬ.` /
  `ЧАСТЬ 3: НЕТ ФИНИША E.`
- `ПРЕДМЕТ «W» НЕ ВЛЕЗАЕТ ПО ВЫСОТЕ.` — шкаф упирается в верх экрана, опустите его ниже.
- `ЛЕГЕНДА: БУКВА «C» — ОБЩИЙ СИМВОЛ, ЕЁ НЕЛЬЗЯ ЗАНИМАТЬ.` — в `legend` уровня использована общая буква.
- `ЛЕГЕНДА: БУКВА «Q» — НЕИЗВЕСТНАЯ ВЕЩЬ «swng».` — опечатка в имени предмета в `legend`.
- `ОШИБКА В ФАЙЛЕ LEVELS.JS, СТРОКА 65.` — сломана запись файла: забыта кавычка или
  запятая. Ищите на этой строке **или на строке выше**.

Поправьте ошибку так же через GitHub и обновите страницу игры.

## Пауза и выбор уровня для тестов

- **Пауза:** кнопка ⏸ в правом верхнем углу (на уровне и в бою), на клавиатуре — P или Esc.
  Меню: ПРОДОЛЖИТЬ / НАЧАТЬ С ПОСЛЕДНЕГО ЗВОНКА (в бою — НАЧАТЬ БОЙ ЗАНОВО) / ЗВУК / ВЫЙТИ
  В ГЛАВНОЕ МЕНЮ. Выбор — пальцем, или стрелками (← → на экране, ↑ ↓ на клавиатуре) и «Прыжком».
  Переключился на другое приложение или вкладку — игра сама встаёт на паузу.
  Звук вкл/выкл запоминается.
- **Выбор уровня:** пока в `CONFIG` в `game.js` стоит `DEBUG_MENU: true`, на титульном экране
  есть пункт «ВЫБОР УРОВНЯ»: любая часть любого уровня, босс (у уровня 2 — мама), «ЗА РУЛЁМ» и «ПЕРЕХОД ДОРОГИ». Список строится сам из
  `levels.js` — новые уровни и части появятся в нём сами. Когда игра готова — поставьте `false`.
